# Font Files

Current font files in this directory:

## Unboxed Custom Font (formerly Pacaembu)

- `Unboxed-Custom-Thin-Trial.woff2` (weight: 100)
- `Unboxed-Custom-Light-Trial.woff2` (weight: 300)
- `Unboxed-Custom-Regular-Trial.woff2` (weight: 400)
- `Unboxed-Custom-Medium-Trial.woff2` (weight: 500)
- `Unboxed-Custom-Bold-Trial.woff2` (weight: 700)
- `Unboxed-Custom-Black-Trial.woff2` (weight: 900)
- `Unboxed-Custom-Ultra-Trial.woff2` (weight: 950)

The Unboxed Custom font is configured in:

- `app/layout.tsx` - imported as `unboxedCustom` with all weights
- `app/globals.css` - configured as CSS variable `--font-unboxed-custom`
- All components - used as `font-unboxed-custom` class

This font provides the custom typography for the entire Unboxed Productions website.
